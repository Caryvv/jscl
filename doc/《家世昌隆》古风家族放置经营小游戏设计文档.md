
# 《家世昌隆》古风家族放置经营小程序游戏设计文档

## 文档信息

- 文档版本：V1.0
- 编制日期：2026年08月12日
- 适用平台：微信小程序、抖音小程序
- 游戏类型：轻放置 + 模拟经营 + 世代养成
- 目标用户：全年龄休闲玩家，偏好国风题材、放置挂机、轻养成类内容的移动端用户

## 一、游戏核心定位

### 1.1 游戏概述

《家世昌隆》是一款适配微信、抖音双端小程序的古风家族经营游戏。玩家从初代平民家族夫妇起步，通过繁衍子嗣、培养族人、经营产业、积累财富，实现家族跨代传承；伴随朝代更迭解锁更多玩法与内容，最终打造绵延百年的名门望族。

游戏主打碎片化轻游玩，支持离线收益，无强制任务，适配小程序用户「即开即玩、随时暂停」的使用习惯。

### 1.2 核心玩法循环

**基础循环**：放置产出银两 → 投资成员/产业升级 → 提升每月总收益 → 繁衍后代扩充家族
**长线循环**：家族成长 → 达成传承条件 → 开启朝代更迭 → 解锁新内容与加成 → 开启新一轮经营

### 1.3 核心卖点

1. **低门槛轻放置**：离线也能累计收益，每日5-10分钟即可完成日常操作，适配碎片化时间
2. **世代传承叙事**：从单人夫妇到百年家族，伴随朝代更迭的成长感与仪式感强
3. **国风轻量化美术**：清新扁平国风画风，视觉舒适，包体小巧，保障小程序秒开体验
4. **双端合规变现**：融合激励广告、内购、社交裂变多种变现模式，适配微信与抖音平台生态

## 二、核心系统设计

### 2.1 家族成员系统（核心主系统）

家族成员是数值产出的核心载体，也是主界面的核心展示内容。

#### 2.1.1 成员基础属性

- **年龄**：以游戏内「月」为单位增长，对应幼年、成年、老年三个阶段
- **身份**：家主、主母、子嗣、旁系亲属，不同身份权限与收益权重不同
- **资质**：分为普通、良好、优秀、天才4档，直接影响每月收益上限
- **职业**：无职业、书生、商人、武官、医者等，不同职业对应不同收益方向与加成效果
- **月收支**：成年成员为正向收益，幼年/老年成员为负向支出（养育/赡养成本）

#### 2.1.2 成员生命周期

1. **幼年期（0-16岁）**：每月消耗养育银两，可通过培养道具提升资质
2. **成年期（17-50岁）**：收益峰值阶段，可婚配、可转职、可派遣跑商
3. **老年期（51岁及以上）**：收益逐步衰减，每月产生赡养支出
4. **离世**：年龄上限触发离世，从家族树中移入族谱，永久保留记录

#### 2.1.3 婚配与子嗣

- 成年子嗣可选择不同背景的婚配对象，对方资质与属性会叠加进家族收益，并影响后代资质
- 子嗣资质随机继承父母双方属性，有概率发生「资质突破」，诞生高天赋后代
- 可通过「添丁有喜」功能主动生育子嗣，消耗对应银两或道具，存在冷却时间

#### 2.1.4 职业体系

- 基础职业：书生（稳定银两收益）、商人（跑商加成）、武官（降低经营风险）、医者（降低养育/赡养成本）
- 传奇职业：高阶稀有职业，通过道具或活动解锁，提供全局家族buff与高额收益加成
- 转职规则：成年成员可消耗资源转职，职业等级随时间自动提升，等级越高收益越强

### 2.2 资源与经济系统

采用三级货币体系，兼顾日常产出、中期养成与付费变现。

| 货币类型           | 核心获取途径                               | 核心用途                                                   |
| ------------------ | ------------------------------------------ | ---------------------------------------------------------- |
| 银两（主货币）     | 成员放置产出、跑商盈利、日常任务、神树产出 | 成员培养、产业升级、生育子嗣、雇佣家丁、普通道具购买       |
| 福缘符（中级货币） | 每日福利、成就奖励、限时活动、邀请好友     | 刷新子嗣资质、抽取传家宝、兑换稀有培养道具、重置职业       |
| 金条（高级货币）   | 充值购买、成就里程碑、节日活动             | 解锁免广告特权、购买限定礼包、加速冷却时间、抽取稀有传家宝 |

#### 结算规则

- 游戏内每自然月自动结算一次收支，总收益 = 全体成年成员产出 - 幼年/老年成员支出 + 产业收益
- 支持离线收益累计，基础上限为12小时，观看激励广告可延长至24小时
- 月收益随成员数量、资质、职业、家族buff动态变化

### 2.3 产业经营系统

#### 2.3.1 跑商系统

- 玩法入口：左侧功能栏「跑商」
- 玩法规则：派遣成年族人选择商路进行贸易，不同商路对应不同风险与收益：
  - 短途商路：低风险、稳定低收益，无亏损概率
  - 中途商路：中风险、中等收益，小概率亏损
  - 长途商路：高风险、高收益上限，存在亏损概率
- 加成规则：商人职业成员带队可提升收益，护院家丁可降低亏损概率
- 广告激励：完成跑商后可观看广告直接翻倍本次收益

#### 2.3.2 家丁系统

- 玩法入口：底部导航「家丁」
- 家丁类型与效果：
  - 账房家丁：按百分比提升全家族银两月收益
  - 护院家丁：降低跑商亏损概率，抵御随机负面事件
  - 管家家丁：提升离线收益累计上限，延长离线收益时长
- 升级规则：消耗银两升级家丁等级，等级越高加成幅度越大

#### 2.3.3 神树系统

- 玩法入口：底部导航「神树」
- 核心规则：
  - 每日可免费浇水，提升神树经验，升级后提供全家族永久收益加成
  - 支持好友互相浇水，邀请好友助力可快速获取成长值
  - 神树达到指定等级解锁专属特权、限定外观与稀有道具
- 社交价值：核心裂变载体，通过好友互助实现低成本用户拉新

### 2.4 世代传承系统（改朝换代）

- 触发入口：左侧功能栏「改朝换代」
- 触发条件：家主达到高龄阈值，或家族声望、财富满足指定条件
- 传承规则：
  1. 选定一名子嗣作为新一代家主，继承家族核心资产与永久加成
  2. 保留家族等级、传家宝、神树等级、全局buff，重置部分临时资源与成员状态
  3. 每完成一次传承，家族声望永久提升，解锁更高阶玩法
- 朝代更迭：每传承3-5代触发一次朝代变更，同步解锁新职业、新产业、新事件、新美术背景
- 家族族谱：记录每一代家主生平、家族重大事件与成就，可随时回溯查看

### 2.5 收集与福利系统

#### 2.5.1 每日福利

每日签到、在线时长奖励、累计登录奖励，基础奖励为银两与福缘符，观看广告可领取双倍。

#### 2.5.2 家族金猪

储蓄返利玩法：玩家可每日存入银两，累计满7天后可取出本金+额外利息奖励；存入金额越高，利息比例越高。

#### 2.5.3 传家藏品

- 收集类长线系统，不同珍宝对应不同永久属性加成
- 获取途径：福缘符抽取、活动奖励、传承解锁、充值礼包
- 藏品可升级，升级后加成效果提升

#### 2.5.4 邀请有礼

社交裂变入口，邀请新玩家进入游戏并完成新手引导，邀请者可获得福缘符、金条、限定道具奖励。

## 三、UI界面架构

参考原型采用「左右侧功能栏+中间主展示区+底部导航」的布局，适配小程序竖屏操作习惯。

### 3.1 整体布局框架

1. **顶部状态栏**
   - 左侧：银两数量 + 月收益标识（+X两/月）、福缘符数量、金条数量
   - 右侧：当前年份/月份、设置按钮、客服入口
2. **左侧功能栏（竖向排列）**
   从上至下：商店、改朝换代、跑商、传奇职业、添丁有喜、免广特惠、充值入口
3. **右侧功能栏（竖向排列）**
   从上至下：每日福利、加桌有礼、家族金猪、传家藏品
4. **中间主展示区**
   默认展示家族关系树，以卡片+连线形式呈现家主、主母、子嗣关系，标注成员年龄与月收支数值。
5. **底部主导航（3个Tab）**
   从左至右：神树、家族（默认页）、家丁

### 3.2 核心页面说明

- **家族主页**：家族树可视化展示，点击成员卡片可查看详情与操作
- **商店页面**：分类展示普通道具、培养道具、限时礼包
- **跑商页面**：商路选择、成员派遣、收益预览
- **神树页面**：神树形象、等级进度、浇水按钮、好友助力入口
- **家丁页面**：三类家丁展示、等级与加成信息、升级按钮

## 四、美术与表现风格

### 4.1 整体视觉调性

- 风格定位：Q版扁平国风，清新治愈
- 主色调：浅青、米白、暖棕为主，低饱和度配色，降低长时间游玩视觉疲劳
- 背景设计：简约山水纹理，不同朝代对应不同底色与背景元素

### 4.2 人物设计规范

- 形象：大头Q版卡通比例，线条简洁，辨识度高
- 服饰：区分年龄、性别、职业、身份，符合对应朝代服饰特征
- 表现：静态卡片为主，少量微动效增强生动性，控制性能消耗

### 4.3 UI设计规范

- 控件：圆角卡片式设计，图标扁平化，按键尺寸适配移动端点击
- 动效：轻量过渡动画，禁用复杂粒子特效与全屏动效，保障小程序运行流畅
- 字体：清晰易读的黑体类字体，关键数值加粗突出

## 五、技术与发行适配方案

### 5.1 技术选型

- **开发框架**：采用 UniApp / Taro 跨端开发框架，一套代码同时适配微信小程序、抖音小程序，降低开发与维护成本
- **渲染方案**：核心界面采用 DOM + CSS 实现，少量复杂效果使用轻量 Canvas，优先保证包体体积与启动速度
- **服务端**：对接微信云开发 / 抖音云开发，无需自建服务器，实现云端存档、数据同步与活动配置
- **性能要求**：主包体积控制在2MB以内，资源按需加载，保障冷启动秒开，低端机型可流畅运行

### 5.2 商业化变现模式

#### 5.2.1 激励视频广告（核心收入）

适配高频轻量场景，不强制干扰玩家：

- 离线收益翻倍
- 跑商结算收益翻倍
- 每日福利双倍领取
- 延长离线收益时长
- 免费刷新子嗣资质
- 免费获取培养道具

#### 5.2.2 内购充值

- 金条直充：不同档位金条，附带首充双倍
- 特权卡：免广告月卡、终身卡，去除激励广告并提供每日特权奖励
- 礼包：新手礼包、成长礼包、限时节日礼包、传家宝限定礼包

#### 5.2.3 插屏广告

在页面跳转、传承结算等节点低频次触发，控制出现频率，避免影响核心体验。

#### 5.2.4 社交裂变

- 好友神树互助浇水
- 邀请新用户得奖励
- 分享战绩/家族族谱获得道具

### 5.3 双平台发行适配

#### 微信小程序

- 接入微信登录、微信支付、微信广告组件
- 支持好友分享、朋友圈分享、公众号关联引流
- 适配微信小程序审核规范与内容要求

#### 抖音小程序

- 接入抖音登录、抖音支付、抖音广告平台
- 支持短视频挂载、达人推广、直播间引流
- 适配抖音信息流获客逻辑，设计可传播的玩法亮点

### 5.4 合规要求

- 接入未成年人防沉迷系统，限制未成年用户游玩时长与充值
- 遵守双平台内容审核规范，无违规题材与元素
- 用户隐私协议与数据处理符合国家法规与平台要求

## 七、附录

### 7.1 术语说明

- **月**：游戏内时间单位，对应现实中固定时长的结算周期
- **传承**：家主换代，开启新一代家族经营的操作
- **全局buff**：对全体家族成员生效的永久属性加成
- **离线收益**：玩家退出游戏后，系统自动累计的银两收益
